# Pixel Vault PW2

A modular travel charging case for the Google Pixel Watch 2.

## 🚧 Project Status

Work in progress.

## Goals

- Travel case for Pixel Watch 2
- Integrated charger
- Cable management
- Modular inserts for different watch bands
- Optimized for Bambu Lab P1S
- Open Source
